## Important accuracy note

The notebook photographs for Practicals 1–5 show the topics, aims, objectives and theory context, but do not show complete source-code pages. Therefore, the Python files in Practicals 1–5 are original educational implementations of the photographed topics, not literal transcriptions of unseen code.

Practical 6 is a programming practical; its runnable Python example is written as a Tic-Tac-Toe Minimax implementation with Alpha-Beta pruning. Practicals 7–9 are tool-exploration activities in the supplied materials. Their folders contain typed procedures, prompt experiments, observation tables and viva preparation rather than fabricated standalone Python programs.

## Where to find the code

- Complete Python code for Practicals 1-6 is in `ALL-PYTHON-PROGRAMS.md`.
- Each of those six programs is also a standalone `.py` file and is embedded in its practical README.
- Practicals 7-9 are tool-based exercises in the supplied documents; they do not prescribe Python source code.

## Editing policy

All explanations and procedures are typed in Markdown. Program source is stored in editable `.py` files. Update these text files directly when your instructor provides corrections or a different required program.
