# Upload these practicals to GitHub

1. Download and extract `SPPU-AI-Practicals.zip`.
2. Open GitHub Desktop and sign in.
3. Choose **File -> Add Local Repository** if the folder is already a Git repository, or **File -> New Repository** and select this extracted folder as the local path.
4. Use `SPPU-AI-Practicals` as the repository name.
5. Review the changed files. The collection contains Markdown notes and Python code only.
6. Enter a commit summary such as `Add typed AI practicals 1-9` and click **Commit to main**.
7. Click **Publish repository** and choose Private or Public.
8. For later changes, edit the `.md` or `.py` files, commit, then click **Push origin**.

Do not add API keys, passwords, private student details or confidential documents.
