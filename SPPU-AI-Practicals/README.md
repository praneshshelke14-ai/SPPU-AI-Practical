## Run the programs

Python 3.9+ is recommended. Practicals 1-6 use only the Python standard library. Open a terminal in the relevant folder and run, for example:

```bash
python practical_02_bfs_dfs_maze_solver.py
```

## Important note about Practicals 7-9

The supplied lab documents describe Practicals 7-9 as tool-exploration activities (ChatGPT, Sora and AI image generation). They specify demonstrations, prompts and observations rather than a required Python program. Their folders contain typed procedures, prompt examples and record sheets. This repository does not add unrelated code and claim it is part of the prescribed practical.
